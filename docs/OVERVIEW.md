# ETStock — ภาพรวมโปรเจกต์

> ระบบช่วยออกใบกำกับภาษีอย่างย่อ (Abbreviated Tax Invoice) สำหรับร้านค้าปลีก
> โดยให้ผู้ใช้ระบุจำนวนขายหน้าร้าน แล้วระบบกระจายออกเป็นรายการใบกำกับภาษีอย่างย่อให้อัตโนมัติ

## 1. วัตถุประสงค์ (Purpose)

ETStock เป็นแอปพลิเคชันเดสก์ท็อปสำหรับจัดการสต๊อกสินค้าและออกใบกำกับภาษีอย่างย่อรายเดือน
ปัญหาที่แก้คือ ร้านค้าที่ขายหน้าร้าน (POS) ต้องมีหลักฐานใบกำกับภาษีอย่างย่อประกอบยอดขาย
แต่การออกทีละใบทำมือนั้นช้าและผิดพลาดง่าย ระบบนี้ให้ผู้ใช้กรอกเพียง **ยอดรวมต่อเดือน**
แล้วสร้างรายการใบกำกับภาษีอย่างย่อให้พร้อมพิมพ์

## 2. ขอบเขต (Scope)

อยู่ในขอบเขต:
- จัดการสินค้าและสต๊อกคงเหลือยกมารายเดือน พร้อมต้นทุน
- บันทึกจำนวนซื้อ / ขาย (ใบกำกับเต็ม) / ขายหน้าร้าน (ใบกำกับย่อ) รายเดือนต่อสินค้า
- สร้างรายการใบกำกับภาษีอย่างย่อจากยอดขายหน้าร้าน
- พิมพ์ใบกำกับภาษีอย่างย่อผ่านหน้า Print Preview ไปยังเครื่องพิมพ์ของระบบ
- กำหนดข้อมูลบริษัท (ผู้ออกใบกำกับ)

ยังไม่อยู่ในขอบเขต (เฟสถัดไป):
- เชื่อมต่อเครื่อง POS / barcode scanner แบบเรียลไทม์
- ระบบผู้ใช้หลายคน / สิทธิ์การเข้าถึง (RBAC)
- รายงานภาษีซื้อ-ภาษีขาย (ภ.พ.30) และงบการเงิน
- ใบกำกับภาษีเต็มรูปแบบ (บันทึกเฉพาะจำนวนเพื่อตัดสต๊อก)

## 3. เทคโนโลยี (Tech Stack)

| ส่วน | เทคโนโลยี |
|------|-----------|
| UI Framework | Avalonia 11.3 (.NET 10, WinExe) |
| รูปแบบสถาปัตยกรรม | MVVM (CommunityToolkit.Mvvm 8.2) |
| ฐานข้อมูล | PostgreSQL |
| Data Access | (แนะนำ) Npgsql / EF Core หรือ Dapper |
| การพิมพ์ | Print Preview Dialog → เครื่องพิมพ์ของระบบ |

## 4. ขั้นตอนการทำงาน (Workflow)

1. **เลือกเดือน/ปี** ที่ต้องการทำรายการ
2. **ดึงข้อมูลสินค้าคงเหลือ (ยกมา) และต้นทุน** มาแสดงบนหน้าจอ
   - เปลี่ยนเดือนได้ด้วยปุ่ม "เปลี่ยนเดือน"
   - นำเข้าข้อมูลคงเหลือใหม่ได้ (import)
   - เพิ่มสินค้าได้
3. **กรอกจำนวน** ต่อสินค้า: จำนวนซื้อ, จำนวนขาย (ใบกำกับเต็ม), จำนวนขายหน้าร้าน (ใบกำกับย่อ)
4. **บันทึกข้อมูล**
5. **สร้างรายการใบกำกับภาษีอย่างย่อ** จากยอดขายหน้าร้าน แล้วสลับไปที่แท็บ "รายการใบกำกับภาษีอย่างย่อ"
   - ถ้าเคยสร้างของเดือนนั้นไปแล้ว → ถามยืนยัน "ต้องการลบแล้วสร้างใหม่หรือไม่?"
6. **พิมพ์รายการใบกำกับภาษีอย่างย่อ** ผ่าน Print Preview

```
เลือกเดือน → โหลดสต๊อกยกมา → กรอกซื้อ/ขาย/ขายหน้าร้าน → บันทึก
        → สร้างใบกำกับย่อ (เตือนถ้ามีอยู่แล้ว) → Print Preview → พิมพ์
```

## 5. หน้าจอ (Screens)

### 5.1 หน้าหลัก — เลือกเดือน/ปี + รายการสินค้า
หน้าจอหลักประกอบด้วยตัวเลือกเดือน/ปี และพื้นที่แสดงข้อมูลแบบ 2 แท็บ:

- **แท็บรายการสินค้า** — ตารางสินค้าแสดง: ชื่อสินค้า, คงเหลือยกมา, ต้นทุน,
  ช่องกรอกจำนวนซื้อ / จำนวนขาย (เต็ม) / จำนวนขายหน้าร้าน (ย่อ), และคงเหลือยกไป (คำนวณ)
  ปุ่ม: เปลี่ยนเดือน, นำเข้าคงเหลือ, เพิ่มสินค้า, บันทึก, สร้างใบกำกับย่อ
- **แท็บรายการใบกำกับภาษีอย่างย่อ** — แสดงใบกำกับที่สร้างของเดือนนั้น
  พร้อมเลขที่ใบกำกับ, วันที่, รายการสินค้า, มูลค่า/ภาษี และปุ่มพิมพ์

### 5.2 หน้าเพิ่มสินค้า
ฟอร์มเพิ่มสินค้าใหม่: รหัสสินค้า, ชื่อสินค้า, หน่วยนับ, ต้นทุน, ราคาขาย

### 5.3 หน้ากำหนดรายละเอียดบริษัท
ข้อมูลผู้ออกใบกำกับ: ชื่อบริษัท, เลขประจำตัวผู้เสียภาษี, ที่อยู่, สาขา,
เลขรูปแบบใบกำกับ (running number prefix), อัตราภาษีมูลค่าเพิ่ม

## 6. กฎทางธุรกิจสำคัญ (Business Rules)

- **คงเหลือยกไป** = คงเหลือยกมา + จำนวนซื้อ − จำนวนขาย − จำนวนขายหน้าร้าน
- คงเหลือยกไปของเดือนหนึ่ง คือคงเหลือยกมาของเดือนถัดไป
- **การสร้างใบกำกับย่อซ้ำ**: หากเดือนนั้นมีใบกำกับย่ออยู่แล้ว ต้องยืนยันก่อนลบและสร้างใหม่
- **VAT**: คำนวณจากอัตราภาษีในข้อมูลบริษัท (โดยทั่วไป 7%) ราคาขายหน้าร้านมักเป็นราคารวมภาษี (VAT-inclusive)
- **เลขที่ใบกำกับ**: running number ต่อเนื่อง อาจรีเซ็ตรายเดือน/รายปีตามการตั้งค่า

## 7. การพิมพ์ (Printing)

ผู้ใช้กดพิมพ์จากแท็บรายการใบกำกับ → เปิด **Print Preview Dialog**
ให้ตรวจสอบรูปแบบก่อน → ส่งไปยังเครื่องพิมพ์ที่เลือกของระบบปฏิบัติการ

## 8. โครงสร้างโปรเจกต์ (ปัจจุบัน)

```
ETStock/
├── ETStock.slnx
├── docs/
│   └── OVERVIEW.md          ← เอกสารนี้
└── ETStock/
    ├── App.axaml(.cs)
    ├── ViewLocator.cs
    ├── Models/              ← (ว่าง) จะใส่ entity/domain model
    ├── ViewModels/
    │   ├── MainWindowViewModel.cs
    │   └── ViewModelBase.cs
    └── Views/
        └── MainWindow.axaml(.cs)
```

โครงสร้างที่แนะนำเมื่อพัฒนาต่อ:
- `Models/` — Company, Product, StockBalance, MonthlyTransaction, AbbreviatedInvoice, InvoiceItem
- `ViewModels/` — MainWindow (แท็บสินค้า + แท็บใบกำกับ), AddProduct, CompanySettings
- `Views/` — หน้าจอตามข้อ 5
- `Services/` — Database (Npgsql), InvoiceGenerator, PrintService
